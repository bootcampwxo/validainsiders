## 2. Recommended Changes

Based on the feedback themes and participant notes, the following three changes are recommended:

### Change 1: Clarify initial workspace setup and folder visibility
* **Description:** Explicitly display the starting folder selection and list the required sample files upfront before starting the first exercise. Provide a clear explanation of workspace boundaries and which files Bob can access.
* **Supporting Response IDs:** `F01`, `F02`, `F03`, `F04`

### Change 2: Enhance prompt templates and provide expected output examples
* **Description:** Add ready-to-copy complete prompt templates, provide secondary examples for report generation, and show the expected output after each prompt step to help participants validate their results.
* **Supporting Response IDs:** `F05`, `F06`, `F07`

### Change 3: Allocate additional time for output inspection
* **Description:** Extend the exercise time allocation by 5 minutes to give participants adequate time to review and inspect generated artifacts and reports.
* **Supporting Response IDs:** `F08`
